# DEATH BOT 2 — К-250

Шутер от третьего лица в постапокалиптическом городе будущего. Боевой робот К-250,
победивший машину Р-111, выходит на последнюю миссию: остановить инженера Хааса —
создателя Р-111, превратившего себя в рогатое чудовище.

Технологии: Three.js + Rapier (физика) + postprocessing, сборка Vite.
Озвучка и звуковые эффекты сгенерированы через ElevenLabs.

## Запуск локально

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

## Сборка

```bash
npm run build    # результат в dist/
npm run preview  # локальный просмотр прод-сборки
```

## Публикация на Vercel

Репозиторий готов к деплою без настройки:

1. Зайдите на [vercel.com](https://vercel.com) → **Add New → Project**.
2. Импортируйте этот GitHub-репозиторий.
3. Vercel сам определит Vite (build: `vite build`, output: `dist`) — жмите **Deploy**.

Переменные окружения не нужны: ключи из `.env` используются только локальными
скриптами генерации ассетов (`scripts/generate-sfx.mjs`, `scripts/generate-voice.mjs`)
и в клиентский код не попадают. Файл `.env` в git не хранится.

Либо из терминала:

```bash
npm i -g vercel
vercel --prod
```

## Управление

- **WASD** — движение, **SHIFT** — бег, **ПРОБЕЛ** — прыжок
- **Мышь** — камера, **ЛКМ** — огонь, **ПКМ** — прицел, **R** — перезарядка
- **+** — саморемонт (тратит ремкомплект; они выпадают из зомби и ящиков, запас до 3)

## Графика

В главном меню есть выбор профиля (НИЗКО / СРЕДНЕ / ВЫСОКО). Профиль
подбирается автоматически по видеокарте, сохраняется в браузере и
автоматически понижается, если FPS стабильно проседает.
